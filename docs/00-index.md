# Cuoc24h Documentation Index

Cuoc24h la nen tang web ket noi khach hang co nhu cau dat xe voi tai xe dich vu taxi tu do, khong bat buoc tai xe phai tham gia cac ung dung goi xe lon.

## Muc Tieu MVP

- Quang cao va hien thi thong tin dich vu xe/tai xe cho khach hang.
- Cho phep khach hang tao yeu cau chuyen di ma khong can dang ky tai khoan.
- Cho phep tai xe dang ky thong tin de tham gia he thong.
- Gui thong tin chuyen di moi len nhom Zalo cho doi ngu dieu phoi/tai xe.
- Cung cap trang admin de quan ly tai xe, yeu cau chuyen di va cau hinh he thong.

## Tech Stack Du Kien

- Backend: Java Spring Boot
- Database: MySQL
- Frontend: Angular, Tailwind CSS
- Deployment: se xac dinh sau, uu tien phuong an don gian cho MVP
- Notification: Zalo group notification thong qua giai phap phu hop kha nang API/thuc thi
