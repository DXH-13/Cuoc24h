# UI/UX Guidelines

## Nguyen Tac Tong The

- Mobile-first vi khach hang va tai xe chu yeu thao tac tren dien thoai.
- Desktop van can day du chuc nang, dac biet cho admin dashboard.
- Giao dien ro rang, nhanh, uu tien dat xe thay vi noi dung marketing dai.
- Form ngan gon, truong bat buoc ro rang.
- Nut goi hanh dong chinh luon de thay tren mobile.

## Public Website

### Home Page

Thanh phan de xuat:

- Header voi logo Cuoc24h va nut "Dat xe".
- Hero ngan gon neu ro dich vu.
- Form dat xe hoac CTA dan den form.
- Khu vuc dich vu/loai xe.
- Quy trinh dat xe 3 buoc.
- Thong tin lien he nhanh.
- Link dang ky cho tai xe.

### Booking Form

Truong thong tin:

- Ho ten
- So dien thoai
- Diem don
- Diem den
- Thoi gian don
- Loai xe
- Ghi chu

UX can co:

- Keyboard mobile phu hop cho so dien thoai.
- Loi validation hien ngay duoi truong.
- Trang thai loading khi gui form.
- Man hinh xac nhan sau khi gui thanh cong.

### Driver Registration Page

Can tach voi booking flow de tranh nham lan khach/tai xe.

Thanh phan:

- Gioi thieu ngan gon loi ich cho tai xe.
- Form dang ky.
- Thong bao quy trinh duyet ho so.

## Admin Dashboard

### Layout Desktop

- Sidebar navigation.
- Top bar co ten admin va logout.
- Bang booking co filter.
- Chi tiet booking co panel rieng hoac page rieng.

### Layout Mobile

- Navigation dang bottom tabs hoac menu gon.
- Danh sach booking hien theo card de doc nhanh.
- Filter don gian theo status.

## Trang Thai Va Mau Sac

Trang thai booking:

- `NEW`: can xu ly.
- `CONTACTING`: dang lien he.
- `ASSIGNED`: da gan tai xe.
- `COMPLETED`: hoan thanh.
- `CANCELLED`: huy.

Trang thai driver:

- `PENDING`: cho duyet.
- `APPROVED`: da duyet.
- `REJECTED`: tu choi.
- `INACTIVE`: tam ngung.

## Accessibility Co Ban

- Label ro rang cho tat ca input.
- Contrast du de doc tren dien thoai ngoai troi.
- Button co kich thuoc cham phu hop.
- Khong chi dua vao mau sac de truyen dat trang thai.
