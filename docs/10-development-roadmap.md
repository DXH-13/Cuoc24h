# Development Roadmap

## Phase 0: Chot Pham Vi

Muc tieu:

- Chot flow dat xe.
- Chot thong tin form tai xe.
- Chot cach gui Zalo cho MVP.
- Chot danh sach trang frontend.

Ket qua:

- Product requirements duoc cap nhat.
- Database schema ban dau duoc thong nhat.

## Phase 1: Backend Foundation

Cong viec:

- Tao Spring Boot project.
- Cau hinh MySQL.
- Tao entity, repository, migration/schema.
- Tao API public cho booking va driver registration.
- Tao global validation/error handling.

Ket qua:

- Co the tao booking va driver qua API.

## Phase 2: Notification

Cong viec:

- Tao notification service.
- Tao notification log.
- Tich hop webhook/API Zalo theo phuong an duoc chon.
- Dam bao booking van thanh cong neu notification loi.

Ket qua:

- Booking moi co thong bao len Zalo hoac log loi ro rang.

## Phase 3: Admin Backend

Cong viec:

- Tao admin authentication.
- Tao API danh sach/chi tiet/cap nhat booking.
- Tao API danh sach/chi tiet/cap nhat driver.
- Tao API xem notification log.

Ket qua:

- Admin thao tac duoc qua API.

## Phase 4: Public Frontend

Cong viec:

- Tao Angular project voi Tailwind.
- Home page mobile-first.
- Booking form.
- Driver registration form.
- Trang xac nhan thanh cong.

Ket qua:

- Khach dat xe va tai xe dang ky duoc tren giao dien.

## Phase 5: Admin Frontend

Cong viec:

- Login page.
- Admin layout.
- Booking list/detail.
- Driver list/detail.
- Cap nhat trang thai.

Ket qua:

- Admin quan ly MVP qua browser.

## Phase 6: Test Va Chuan Bi Release

Cong viec:

- Test happy path dat xe.
- Test validation form.
- Test Zalo notification failure.
- Test admin authentication.
- Test responsive mobile/desktop.
- Viet huong dan setup local.

Ket qua:

- MVP san sang deploy noi bo hoac demo.

## Viec Nen De Sau MVP

- Tai khoan khach hang.
- Tai xe dang nhap va nhan chuyen tren web.
- Tinh gia tu dong.
- Thanh toan online.
- Dinh vi realtime.
- Chat khach/tai xe.
- Rating/review tai xe.
